# Simple Calculator

A basic calculator application built with Python's Tkinter library.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, division
- Decimal point support
- Clear function
- Error handling for invalid expressions
- Clean, user-friendly interface

## Requirements

- Python 3.x
- Tkinter (included with most Python installations)

## Installation

1. Ensure Python is installed on your system
2. Clone or download this repository
3. No additional packages needed - Tkinter comes with Python

## Usage

Run the calculator:

```bash
python calculator.py
```

## Controls

- **Number buttons (0-9)**: Enter digits
- **Operators (+, -, *, /)**: Perform calculations
- **Decimal (.)**: Add decimal points
- **Equals (=)**: Calculate result
- **Clear (C)**: Reset the calculator

## How It Works

1. Click number and operator buttons to build your expression
2. Press **=** to evaluate
3. Press **C** to clear and start over
4. Invalid expressions will display "error"

## Example

```
7 + 3 * 2 = 13
15.5 / 2 = 7.75
```

## Interface

- **Window size**: 400x400 pixels (fixed)
- **Color scheme**: Light gray background with white number buttons
- **Layout**: Standard calculator grid (4x5 buttons)
